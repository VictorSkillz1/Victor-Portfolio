# Victor Fabonmi Portfolio

Responsive editorial-style portfolio built with Next.js, React, TypeScript, and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Personalize before launch

- Replace the portrait image URL in `app/page.tsx` with your own professional photograph.
- Verify the project names, descriptions, preview images, and live URLs in the `projects` array.
- Update the email address and WhatsApp link in the contact section.
- Add your real contact details and social links before publishing.

## Deploy

Import this repository into Vercel. Select the Next.js framework preset and keep the default build settings. No environment variables are required for this starter.
